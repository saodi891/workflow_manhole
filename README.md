# 井盖桌宠 (manhole-pet)

一个在 Windows 10/11 上运行的桌宠软件，旨在解决关机重启后打开的窗口工作流丢失的问题

没有美术资源时，程序会自动画一个「井盖占位图」，可以先跑起来看效果。

> 技术栈：Python 3.10+ / PySide6。窗口控制用系统自带的 ctypes 调 Win32 API，无额外原生依赖。

## 快速开始

1. 双击 `scripts\install.bat` 装依赖（只需一次，需要联网）
2. 双击 `scripts\run.bat` 直接运行
3. 双击 `scripts\build.bat` 打包成 exe，成品就在项目根目录：`workflow_manholeV0.4.exe`

> 需要电脑装了 Python 3.10+（命令行 `python --version` 能看到版本号即可）。
> 打包好的 exe 拷到别的电脑（Win10 及以上）可直接双击运行，对方无需装 Python。

## 操作方式

| 操作 | 效果 |
|------|------|
| 左键单击 | 播放 wait 动画，并在井盖两侧弹出快捷面板。**面板展开后，再次单击或开始拖动都会立即收起** |
| 左键拖动 | 把它拎起来移动，松手后按重力设置落地 / 停在原处 / 趴到墙上 |
| 双击 | 播放 click 反应动画 |
| 右键 / 托盘图标 | 完整菜单：设置、启动工作流、行为模式、重力、保持最前、睡觉、回到中间、退出 |

单击弹出的快捷面板：

```
   ┌──────────┐              ┌──────────┐
   │ 启动工作流 │   [井盖]   │ 睡觉/唤醒 │
   │   设置    │            │  更改重力  │
   │  切换行为  │            │  退出井盖  │
   └──────────┘              └──────────┘
       左侧                      右侧
```

## 功能详解

右键井盖或点托盘图标 →「设置…」，分四个页签：

### 1. 启动工作流
一键按顺序拉起一套常用软件，并还原到你关机前的窗口位置和大小

**多套配置（v0.3）**：工作流保存成 `config\` 文件夹里的一个个 `.json`，可以存多套、随时切换。
- **当前配置** 下拉框：选中哪个，下面的列表和「启动工作流」就用哪个。下面的增删改会实时存回选中的那个 json。
- **新建 / 另存为 / 删除 / 导入配置**：新建空配置、把当前列表另存为新名字、删除、从别处导入一个 json。
- `default.json` 是默认配置，井盖启动时用它；`latest.json` 是临时槽。这两个删除只会清空列表、不会删文件。
- **暂存当前桌面→临时**：一键把此刻桌面上打开着的所有窗口（位置尺寸）快照进 `latest.json`，每次覆盖。

单套配置内的操作：
- **添加程序**：选一个 exe 加进列表
- **记录已开窗口**：先把程序窗口摆到想要的位置和大小，再点这里勾选，会连同**当前的位置和尺寸**一起记录
- **编辑 / 删除 / 上移 / 下移**：调整启动顺序和参数（路径、启动参数、坐标）
- **立即启动工作流**：依次启动列表里的程序；勾了「还原窗口」的会被自动移动/缩放回记录时的位置和尺寸
- 右键菜单里的「启动工作流」是同一功能的快捷入口

> 配置文件是普通 json（UTF-8，中文可读、中文文件名也支持），可以直接拿去分享或手改。
> 窗口还原靠 Windows API 按 exe 名匹配新开的窗口。个别程序是「启动器再拉起主进程」或开屏很慢，可能匹配不到，这时会跳过还原、只负责启动

### 2. 更改风格
用一套 gif 换掉井盖外观。风格包是一个 **.zip 或文件夹**，里面放同名 gif：
```
idle.gif  walk.gif  drag.gif  sleep.gif  click.gif  wait.gif
```
- gif 会被逐帧拆开当动画播放；缺哪个状态就沿用默认井盖
- 选好即时生效，下次启动自动记住。「恢复默认井盖」可还原

### 3. 行为模式 / 重力
- **待机**（默认）：一动不动待在原地
- **散步**：隔一会儿随机四处走动，撞到屏幕边缘自动掉头
- **重力开关**（默认关）：
  - 无重力：松手停在原地不下落；靠近屏幕左右两侧会**趴到墙上**，散步模式下还会沿墙上下爬行
  - 有重力：松手掉到地面，只在底部走动。
- 模式和重力在右键菜单里也能快速切换

### 4. 窗口（保持最前）
勾选后井盖始终盖在其它窗口之上；取消则会被其它窗口遮住。设置页和右键菜单都能切换

> 所有设置自动保存在 `%APPDATA%\井盖桌宠\settings.json`，下次启动自动恢复

## 放你的美术资源

把帧图放进 `assets` 下对应文件夹即可：

```
assets/
  idle/    待机（呼吸、眨眼等循环）
  walk/    走动（默认帧朝左，朝右时程序自动翻转）
  drag/    被拖起来
  sleep/   睡觉
  click/   双击反应
  wait/    左键单击、弹出功能面板时的等待动作
```

命名规则：
- 同一动作里，帧按文件名排序播放，建议 `001.png` `002.png` `003.png` ……
- 推荐 PNG，透明背景，正方形，边长 ≥ 128
- 支持 `.png` / `.webp` / `.gif`
- 某个文件夹留空 → 自动用井盖占位图顶替

> 仓库默认不带美术资源，各状态文件夹为空时一律使用内置的程序化井盖占位图（见 `assets_loader.py`）。放入你自己的帧图即可替换

## 调参数

打开 `config.py`，常用的几个：

- `PET_SIZE` 显示大小（像素），默认 128
- `FRAME_INTERVAL_MS` 每帧停留毫秒，越小动得越快
- `WALK_SPEED` 走动速度
- `ALWAYS_ON_TOP` 是否默认总在最前
- `IDLE_*` / `WALK_*` 控制待机和走动的时长节奏

## exe 图标（可选）

想让 exe 有自定义图标，把一个 `icon.ico` 放到项目根目录（和 `workflow_manholeV0.4.exe` 同级），再跑 `scripts\build.bat` 会自动用上

## 文件说明

| 文件 | 作用 |
|------|------|
| `pet.py` | 主程序：窗口、拖拽、行为状态机、菜单、单击面板 |
| `assets_loader.py` | 读取帧图 / gif 风格包，缺图时生成井盖占位图 |
| `settings.py` | 偏好读写（置顶/行为/重力/风格/当前配置，存到 %APPDATA%） |
| `configs.py` | 工作流配置库：管理 `config\` 下的多套 json |
| `ui.py` | 设置窗口（工作流 / 风格 / 行为 / 窗口 四页） |
| `wf_runner.py` | 工作流：依次启动程序并还原窗口 |
| `winapi.py` | Windows 窗口工具（枚举 / 移动 / 缩放，纯 ctypes） |
| `config.py` | 所有可调参数 |
| `requirements.txt` | 依赖清单 |
| `scripts\` | `install.bat` / `run.bat` / `build.bat`（会自动切到项目根目录执行） |
| `assets\` | 美术资源（各状态帧图） |
| `config\` | 工作流配置（首次运行自动创建，存你的多套 json） |
